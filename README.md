# Storm Veil Tune Deck — Releases

Installers and updates for **Storm Veil Tune Deck**, the simple music manager for the Surfans F22.

**Install:** download `StormVeil.TuneDeck-win-Setup.exe` from the latest release on the right and run it. No admin rights needed. Once installed, Tune Deck keeps itself up to date.

This repository holds release notes only; the app's source is maintained privately by Storm Veil Technologies.
